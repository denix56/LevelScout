## Data

LevelScout ships game data in `LevelScout/data/`: data from ForeverDB.net, which includes
CMaNGOS classic-db data. It is generated by `tools/import/import.lua` from ForeverDB alone.
LevelScout also reads data at runtime from the QuestieDB addon the player installs (a required
dependency); none of QuestieDB's data is shipped with LevelScout.

How LevelScout complies with this term:
- Every generated data file starts with that line. A test (`tests/test_realdata.lua`) enforces
  it.
- The attribution appears here, in [NOTICE.txt](NOTICE.txt), in the addon's TOC notes, and in
  game under `/ls about`.

LevelScout takes the following from ForeverDB:
- objective counts;
- quest, objective and turn-in locations observed in Forever;
- drop chances measured in Forever;
- quest XP captures and its XP curve;
- pace (seconds per kill, item and object);
- zone levels;
- travel data (flight paths and times, hubs, walking distances);
- the list of classic quests that exist in the Forever client.

### QuestieDB (https://github.com/Questie/QuestieDB), read at runtime

QuestieDB is the database addon of the Questie project, licensed under GPL-3.0
(https://www.curseforge.com/wow/addons/questiedb). LevelScout requires it and reads from the
installed copy, through its public `LibQuestieDB` API and with QuestieDB's own corrections for the
player's faction and class (nothing of it is copied into LevelScout's files):
- quests and their structure;
- NPC and object spawns;
- item drop sources;
- drop rates, which QuestieDB compiled from Wowhead and CMaNGOS data;
- prerequisites, race and class requirements;
- quest XP;
- zone mapping and race/class masks.

### CMaNGOS classic-db (https://github.com/cmangos/classic-db)

The open World of Warcraft Classic 1.12 world database, by the CMaNGOS project and its
contributors, licensed under GPL-3.0. It reaches LevelScout through ForeverDB (classic objective
counts, prerequisites and spawns; shipped) and through QuestieDB (read at runtime).

### LibDeflate (import tools and tests only)

`tools/import/vendor/LibDeflate.lua`, by Haoqian He, is under the zlib License (notice kept in
the file). It is used by the import tools and the tests only (`tools/import/client.lua`, loaded
by the ForeverDB import and by the QuestieDB loader the tests use); not shipped in the addon.
